# AVEVA reference

A private, static knowledge base on AVEVA's product portfolio, licensing model, public price evidence and Middle East footprint, with an interactive product-relationship chart. Research as of 25 Oct 2026.

Plain HTML, CSS and JavaScript. No build step, no npm, no framework. The only external request is Google Fonts (optional; the site falls back to system fonts).

## Layout

```
index.html              Overview, cautions, confidence legend, headline facts
products.html           Portfolio table, filterable by family, searchable
relationships.html      Interactive SVG relationship chart + layer stack
licensing.html          How Flex credits work
pricing.html            Sortable price-evidence table, burn rates, GCC estimate method
middle-east.html        Footprint, partners by country, confirmed customers
positioning.html        Layer table and positioning lines for Landmark / DFS
open-questions.html     Checklist
sources.html            Grouped link lists
assets/style.css        Shared stylesheet (light/dark, print)
assets/site.js          Theme toggle, confidence chips, sortable tables, filters
assets/search.js        Site-wide client-side search
assets/relations.js     Draws the relationship chart from relations.json
assets/relations.json   Chart data: layers, nodes, edges
assets/search-index.json  Generated by tools/build_index.py
tools/build_index.py    Rebuilds the search index from the HTML pages
netlify.toml            Publish directory and security headers
```

## Deploy to Netlify via GitHub

1. Create an empty GitHub repository (private is fine), for example `aveva-reference`. Do not add a README or .gitignore from the GitHub UI; this folder already has both.
2. Push this folder as the repo root:

   ```sh
   cd path/to/this/folder
   git init
   git add .
   git commit -m "AVEVA reference site"
   git branch -M main
   git remote add origin git@github.com:YOUR-USER/aveva-reference.git
   git push -u origin main
   ```

3. In Netlify: **Add new site → Import an existing project → GitHub**, pick the repository.
4. Build settings:
   - Build command: leave **empty**
   - Publish directory: `.`
   - (Both are already set in `netlify.toml`, so Netlify will pick them up automatically.)
5. Deploy. Every later push to `main` redeploys.

The site is marked `noindex` and the headers deny framing. For a private reference you may also want to enable Netlify's password protection or Netlify Identity on the site.

## Preview locally

Any static server works. The relationship chart and search load JSON with `fetch()`, which browsers block on `file://` URLs, so serve the folder rather than double-clicking a file:

```sh
python3 -m http.server 8000
# then open http://localhost:8000/
```

## Update content

- **Text, tables, prices:** edit the relevant `.html` file directly. Keep the `[Certain]`, `[Likely]`, `[Guessing]` wording either as a `<span class="tag tag-certain">Certain</span>` chip or as literal `[Certain]` text; `site.js` converts the literal form into chips on load.
- **Relationship chart:** edit `assets/relations.json`. Nodes need `id`, `label`, `layer`, `desc` and optionally `formerly`; edges need `from`, `to`, `rel` and `evidence` (`documented` or `inferred`). A label containing "pending" is drawn with a dashed border. Left-to-right order inside a lane is set in the `ORDER` map at the top of `assets/relations.js`; unlisted nodes are appended.
- **Search index:** after editing any page or `relations.json`, rebuild and commit the index:

  ```sh
  python3 tools/build_index.py
  ```

  It only uses the Python standard library.
